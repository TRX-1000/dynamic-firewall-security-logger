## Comparison across run medians

- connect_ms: baseline 6.487, firewall 6.281; change -3.2%.
- first_echo_ms: baseline 28.204, firewall 29.318; change +4.0%.
- steady_median_ms: baseline 0.037, firewall 0.030; change -18.9%.
- application_mbps: baseline 97.128, firewall 105.771; change +8.9%.

Negative latency change is faster; negative goodput change is slower. Small differences can be VM noise. Report each round, sample counts and failures. First echo includes server connection logging; steady echo excludes it.

Blocking measurements are in each demo/security.jsonl (BLOCK_REQUEST, BLOCK_CONFIRMED, RECOVER) and demo/recovery.json. Barrier time confirms switch processing, not first packet loss; recovery probes provide an observed bound rather than an exact expiry timestamp.
